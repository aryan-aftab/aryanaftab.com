Selected work

Projects that show how I think.

Finance · Excel · Scenario analysis

Financial modelling BDRR investments

Applied financial analysis to evaluate the profitability of the Build, Develop, Refinance, Repeat (BDRR) strategy compared to traditional investments like the S&P 500. Built a custom Excel model with realistic market data and assumptions to compare return paths and support investment decisions.

AI · LLMs · Local inference

Local AI Agent

A locally hosted analytical assistant using open-source models, tuned for code generation and quantitative work. Runs without third-party cloud infrastructure, which keeps data on machines I control; useful when privacy and regulatory uncertainty matter.

Infra · WireGuard · Networking

Raspberry Pi reverse proxy

Needed remote access to internal services while stuck behind CGNAT with no static IP from the ISP. A Raspberry Pi 5 connects to a VPS over WireGuard; iptables forwards traffic so the Pi effectively has a stable address without opening the whole LAN.

Hardware · KiCad · QMK

Ergonomic split keyboard

Custom split keyboard inspired by the Halmak layout. Modified open-source PCB designs in KiCad for a staggered, natural hand position, then flashed firmware with QMK. After settling on a layout, typing speed went from about 120 WPM to about 150 WPM.
